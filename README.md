### Post-Trap Futurism Radio (`radio/`)

A self-contained listening room for the movement: full recordings of **Zooted Zone**, **Doves & Diamonds**, and **Diabolique**, catalog art, platform links, the learning set, reactions, and a JSON relay for agents. All assets are local (`radio/assets/`) — the app works offline once loaded.

## Deploy

Push to `main` — GitHub Pages serves from `/`. Add a new app as a new top-level folder with its own `index.html`.
